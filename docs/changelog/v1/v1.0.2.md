# StubbornTCP v1.0.2 Changelog

**Release Date**: October 2025
**Release Type**: Patch

---

## Overview

Adds the connection handle to the `data` event and documents each event's arguments.

---

## 💥 Breaking Changes

### `data` event arguments now include the handle

Despite being a patch, this changes the `data` event's arguments from `(data, instance)` to `(data, handle, instance)`, matching the other events. Listeners that only use the first argument are unaffected; listeners that read the client from the second argument now receive the handle there and must move to the third argument:

```javascript
client.on("data", (data, handle, instance) => {
	console.log(`[${handle}]`, data.toString());
});
```

## 📚 Documentation

- The JSDoc `@fires` list now states the arguments of every event.

## Upgrade notes
