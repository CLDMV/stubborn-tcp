# StubbornTCP v1.0.3 Changelog

**Release Date**: October 2025
**Release Type**: Patch

---

## Overview

Debug output moves from `console.log` to a `debug` event, and a zero or negative timeout now disables the socket timeout instead of failing.

---

## 💥 Breaking Changes

### `debug: true` emits `debug` events instead of printing

Despite being a patch, this changes what `debug: true` does. It used to write messages straight to `console.log`; it now emits a `debug` event with `(message, handle, instance)`, and nothing is printed unless you listen for it:

```javascript
client.on("debug", (message) => console.log("DEBUG:", message));
```

Errors caught inside callbacks (`rxFunc`, `onConnect`, `onDisconnect`, `onError`, `onTimeout`, heartbeat functions) are reported through the same event, with the error's message rather than the error object.

---

## 🐛 Bug Fixes

### Zero or negative timeouts disable the timeout

`setTimeout(timeout)` with `0` or a negative value now disables the socket timeout. A negative value used to be passed straight to the socket and threw `ERR_OUT_OF_RANGE`. The `connectionTimeout` option is documented as accepting `0` or a negative value to disable the timeout.
