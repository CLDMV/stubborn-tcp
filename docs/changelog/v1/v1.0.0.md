# StubbornTCP v1.0.0 Changelog

**Release Date**: October 2025
**Release Type**: Major (initial release)

---

## Overview

First release of `@cldmv/stubborn-tcp`, a TCP client for Node.js that keeps reconnecting when the connection drops.

---

## ✨ Features

- `StubbornTCP` constructor taking an options object (callable with or without `new`), built on `EventEmitter`. Passing `host` and `port` connects immediately; otherwise call `open(host, port)`.
- Automatic reconnection with exponential backoff: `autoReconnect`, `reconnectDelay`, `maxReconnectDelay`, `reconnectBackoffFactor` and `maxReconnectAttempts` (`-1` for unlimited), plus `resetReconnectState()`.
- Socket tuning: `keepAlive`, `keepAliveInitialDelay`, `noDelay` and `connectionTimeout` options, and the matching `setKeepAlive()`, `setNoDelay()` and `setTimeout()` methods.
- Application heartbeat: `heartbeatEnabled`, `heartbeatInterval`, `heartbeatFunc` (one function or an array that is cycled through) and `heartbeatResetOnActivity`, with `enableHeartbeat()`, `disableHeartbeat()`, `addHeartbeatFunction()` and `clearHeartbeatFunctions()`.
- TLS options (`tls`, `tlsOptions`) and TLS helpers (`getPeerCertificate()`, `getCipher()`, `isAuthorized()`, `getAuthorizationError()`). TLS connections did not actually work until [v1.0.4](./v1.0.4.md).
- Events: `connect`, `data`, `disconnect`, `error`, `timeout`, `maxReconnectAttemptsReached`, `heartbeat`, `heartbeatFailed`, `secureConnect`, `keylog` and `OCSPResponse`.
- Legacy callbacks (`rxFunc`, `onConnect`, `onDisconnect`, `onError`, `onTimeout`) and legacy names (`Open()`, `Write()`, `OnConnectFunc`, `OnDisconnectFunc`) for code ported from older clients.
- Read-only state: `connectState`, `openState`, `handle`, `isSecure`, `localAddress`, `localPort`, `remoteAddress`, `remotePort`.
- ESM entry (`index.mjs`) and a CommonJS entry (`index.cjs`).

---

## Upgrade notes

- Initial release; nothing to upgrade from.
- In this version `require("@cldmv/stubborn-tcp")` returns a **Promise** that resolves to the constructor, not the constructor itself. [v1.0.1](./v1.0.1.md) changes that.
